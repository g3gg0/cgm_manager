# CubeGM Manager

Web UI for maintaining CubeGM SD card game lists.

## GitHub Pages

This repository deploys `cgm_manager.html` as the site root (`index.html`) via GitHub Actions.

Expected page URL:

- `https://g3gg0.github.io/cgm_manager/`

### One-time setup in GitHub

1. Open repository settings.
2. Go to **Pages**.
3. Set **Source** to **GitHub Actions**.

After that, every push to `master` will publish the page.
